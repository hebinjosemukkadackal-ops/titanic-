# titanic-# Exploratory Data Analysis (EDA) — Titanic Dataset

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic dataset to identify patterns, relationships, and trends that influenced passenger survival.  
The analysis uses statistical summaries and visualizations to extract meaningful insights.

---

## 🎯 Objective
- Explore the Titanic dataset using statistical and visual methods  
- Identify relationships between passenger features and survival  
- Detect trends, distributions, and anomalies  

---

## 🛠 Tools & Libraries
- Python  
- Pandas  
- Matplotlib  
- Seaborn  
- Google Colab  

---

## 📂 Dataset
Dataset used: **Titanic train.csv**  

Features include:
- PassengerId  
- Survived  
- Pclass  
- Name  
- Sex  
- Age  
- SibSp  
- Parch  
- Ticket  
- Fare  
- Cabin  
- Embarked  

---

## 🔎 EDA Steps Performed
1. Data loading and inspection  
2. Data structure analysis (`info`, `describe`)  
3. Missing value analysis  
4. Distribution analysis (histograms)  
5. Outlier detection (boxplots)  
6. Survival analysis by gender and class  
7. Feature relationships (scatterplots, pairplots)  
8. Correlation analysis (heatmap)  
9. Observations for each visualization  
10. Summary of findings  

---

## 📊 Key Findings
- Female passengers had significantly higher survival rates  
- 1st class passengers were more likely to survive  
- Higher fare correlated with higher survival probability  
- Age showed weaker relationship with survival  
- Majority of passengers were in 3rd class  
- Missing values present in Age and Cabin columns  

---

---

## 🚀 Conclusion
EDA revealed that passenger class and gender were the most influential factors affecting survival on the Titanic. Visualization and statistical exploration provided meaningful insights into passenger demographics and survival patterns.
